# Data-Driven SEO & Marketing Investment Decision-Support Tool

An interactive analytical web application for exploring SEO and digital marketing performance, customer acquisition costs, customer lifetime value, and marketing budget allocation scenarios.

## Overview

This project provides a dashboard for analysing marketing-channel performance using search, traffic, conversion, spending, CAC, and LTV metrics.

Users can adjust marketing inputs and experiment with different budget allocations to explore how changes in investment may affect projected customers, acquisition costs, and customer value.

The application is designed as a decision-support and modelling tool rather than a prediction system. Results are based on the assumptions and synthetic data entered into the application.

## Features

- Interactive marketing analytics dashboard
- Multiple marketing channels
- SEO performance analysis
- Paid Search analysis
- Social Media analysis
- Search and traffic metrics
- Conversion-rate analysis
- Marketing-spend analysis
- Customer Acquisition Cost (CAC) calculation
- Customer Lifetime Value (LTV) analysis

- Projected customer value/revenue
